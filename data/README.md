# Data directory

`processed/Sundarbans_Multisensor_Feature_Cube_public.csv` contains the processed PSP-year feature cube used for the public reproducibility workflow. Precise latitude/longitude columns have been removed.

`processed/PSP_Spatial_Block_Assignments_public.csv` contains reproducible block membership for the 3-, 5- and 10-block sensitivity analyses without publishing coordinates.

`results/` contains final validation and ecological diagnostic tables used in the revised manuscript.

See `DATA_DICTIONARY.csv` for column categories and missingness.
